SYSTEM GUIDE

INSTRUCTIONS

Everything you need to understand MS HABIT MACRAS V2.

LOCAL DATA

MS HABIT MACRAS stores your challenge, daily progress and records directly in this browser using localStorage.

APP DATA

Your challenge data remains available after closing or reopening the app and after a normal browser refresh on the same browser/device.

NO CLOUD

No account, login, server, cloud database or internet connection is required for the app's core functionality.

ONE ACTIVE CHALLENGE

V2 maintains one active challenge at a time. Completed challenges can be packed and saved into RECORDS.

GOALS OPTIONAL

Add daily goals or leave them empty. When goals exist, every goal must be checked before the current day can be completed.

DAY SYSTEM

The start date is Day 1 and the end date is the final day. Only the real current challenge day can be completed. Future days remain locked.

MISSED DAYS

A day that passes without completion becomes MISSED. Missed days cannot be falsely completed later.

RECORD SYSTEM

When a challenge reaches 100%, use PACK & SAVE RECORD. The complete daily history and goal states are copied into your local records archive.

EXPORT

Open any saved record and use SAVE CHALLENGE FILE to export that record as a JSON file.
